# DarkForest

A dark sci-fi web experiment: transmit Earth's coordinates and see who answers.

## About

An interactive, Trisolaris-inspired novelty site. Visitors negotiate terms with an extraterrestrial civilization that has run out of stable suns and has its eye on Earth. It's a joke taken just seriously enough to feel unsettling.

## Live Site

https://d7741.github.io/DarkForest/

## Features

- Interactive transmission sequence — a scripted negotiation between visitor and alien correspondent
- Typewriter-style dialogue synced to a reactive waveform indicator
- A simulated transmission counter, persisted locally in the browser (not a global or server-backed count)
- Fluid, responsive interface that scales across viewport sizes
- Optional support link to Ko-fi
- Static site, deployed via GitHub Pages

## Tech

- HTML
- CSS
- Vanilla JavaScript
- GitHub Pages

No frameworks, no build step, no backend.

## Privacy / Architecture

The entire site is static and runs client-side only. Anything you type never leaves your browser — there's no server, no database, and no account required.
